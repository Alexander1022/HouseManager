# HouseManager

A Java application for managing household finances and records.

## About

HouseManager is a lightweight tool designed to help you organize and track your household financial data, including expense tracking and tax payment records.

## Getting Started

### Prerequisites

- Java 8 or higher
- Maven

### Build & Run

```bash
git clone https://github.com/Alexander1022/HouseManager.git
cd HouseManager
mvn clean install
mvn exec:java
